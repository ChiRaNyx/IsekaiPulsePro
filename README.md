# Isekai Pulse Pro

**[Скачать Pro для Windows x64](https://github.com/ChiRaNyx/IsekaiPulsePro/releases/latest/download/IsekaiPulsePro-Windows-x64.zip)**

Переносная панель для **Isekai: Waifu Overlord**, Windows 10/11 x64.

Для запуска скачайте **IsekaiPulsePro-Windows-x64.zip** из Assets релиза,
распакуйте целиком и откройте **IsekaiPulsePro.exe**. Резервный запуск —
**Start_Pro.bat**. Python и зависимости включены, Node.js не нужен.

Адрес панели: **http://127.0.0.1:8768**.
Запустите игру, откройте деревню и нажмите **«Обновить из игры»** под сменой темы.
Прошлые ивенты автоматически восстанавливаются из сохранения при этом ручном обновлении.
Если игра не найдена автоматически, выберите её EXE в настройках.

Сохранены 10 разделов исходной панели:

- Мои персонажи, здания и доход, чек-поинты.
- Ферма с помощницей Тарой и миссии.
- Древо навыков и питомцы.
- Ивенты, журнал призывов и инструменты.

Вкладки **«Бой v2»** и **«Арена»** отсутствуют. В остальных разделах сохранены
исходные действия, в том числе улучшение зданий и применение расстановки.
Они выполняются по явному запросу и могут расходовать ресурсы игры.

В чистой поставке нет аккаунта, истории, команд, замеров и готовых моделей
напарниц. Их изображения извлекаются для полученной коллекции из установленной игры.
Публичные справочники и игровые значки включены. Защита совместимости SHA/MVID сохранена.

Переносите **всю папку вместе с runtime и tools**. Для завершения процесса
используйте **«Завершить Pro»**; закрытие вкладки не останавливает приложение.

**IsekaiPulsePro-Source.zip** — исходники без runtime; для обычного запуска
нужен полный Windows-архив. Подробная инструкция: `README_RU.txt`.

Подготовка проверена на синтетических данных; отдельные DLL Pro собраны,
но к реальной игре при подготовке не подключались. Isekai Pulse Pro — неофициальная
панель; название и игровые материалы принадлежат их правообладателям.

Автоматические архивы GitHub **Source code** содержат файлы репозитория.
Полные исходники программы — отдельный **IsekaiPulsePro-Source.zip** в Assets релиза.
